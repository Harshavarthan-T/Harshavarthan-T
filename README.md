# Harshavarthan T

I study embedded systems at FH Dortmund. My projects explore how software systems behave when a service fails, a message arrives twice, or several components need to coordinate.

## Selected projects

- [Lead capture and campaign reporting](https://github.com/Harshavarthan-T/lead-workflow-ai-drafts) — An n8n form records enquiries in Google Sheets and creates Gmail drafts for review. I tested repeat submissions and a failed model request to check what happens to the original contact.
- [Truck platooning](https://github.com/Harshavarthan-T/Truck-Platooning-Distributed-Systems) — A distributed systems project exploring coordination and communication between vehicles.
- [Kubernetes incident triage](https://github.com/Harshavarthan-T/ai-kubernetes-incident-triage) — A portfolio project in development exploring AI-assisted triage and human-approved remediation.
